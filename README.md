# Estudio Relax

Convierte una imagen en un vídeo relajante largo (chimenea, nieve, lluvia, velas...) con sonido, gratis y en el navegador.

- Efectos animados en bucle sin cortes: nieve, lluvia, relámpagos, niebla, estrellas, luciérnagas, chispas, fuego y velas.
- Sonidos generados propios: chimenea, lluvia, viento, olas, truenos y música suave. Se puede añadir música libre de derechos.
- Exporta MP4 1080p de 1 minuto a 8 horas con WebCodecs. El bucle se codifica una vez y se repite, así una hora tarda pocos minutos.
- Mejor en Chrome o Edge de ordenador para vídeos largos.

Usa [mp4-muxer](https://github.com/Vanilagy/mp4-muxer) (licencia MIT, incluida).
